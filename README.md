# صفحه اصلی فروشگاه اینترنتی (Responsive E-commerce Homepage)

این پروژه یک صفحه اصلی (Homepage) برای یک وبسایت فروشگاهی است که با هدف تمرین و تقویت مهارت‌های فرانت‌اند پیاده‌سازی شده است.

هدف اصلی این پروژه، پیاده‌سازی یک رابط کاربری واقعی و ریسپانسیو با استفاده از HTML ،CSS و Bootstrap بوده است.

---

##  تکنولوژی‌های استفاده شده
- HTML5
- CSS3
- Bootstrap 5
- طراحی واکنش‌گرا (Responsive Design)

---

##  امکانات پروژه
- طراحی کاملاً ریسپانسیو (موبایل، تبلت و دسکتاپ)
- رابط کاربری مدرن فروشگاهی
- بخش Hero (بنر اصلی)
- نمایش محصولات به صورت کارت
- نوار ناوبری (Navigation Bar)
- فوتر سایت

---

##  هدف آموزشی پروژه
این پروژه با دنبال کردن یک دوره آموزشی آنلاین ساخته شده و در حین پیاده‌سازی، برای تقویت مهارت‌های فرانت‌اند شخصی‌سازی و تمرین شده است.

---

## مهارت‌هایی که در این پروژه تمرین شده
- کار با Bootstrap Grid System
- استفاده از Flexbox برای چیدمان
- پیاده‌سازی طراحی واکنش‌گرا
- نوشتن HTML و CSS تمیز و ساختارمند
